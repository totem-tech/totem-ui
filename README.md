# Installation
Make sure that the current version of node and webpack is installed. You can find the expected version of node in "engines" in `package.json`.

```shell
    # install node version
    sudo n install <version>
    # install webpack versions 
    sudo npm install --save-dev webpack webpack-cli
```

## Local development
When running on a development machine you need to add a local certificate. Follow the "how-to" found here: /sslcert/how-to.md.

---

# Running the app

```shell
    # install dependencies
    npm install
    # build and start the app
    npm start 
```
